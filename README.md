# 净播 AdPrune

m3u8 本地广告清理器 —— 不转码、不损画质。

纯文本处理工具：读取本地 m3u8 → 按三层规则识别广告分片 → 删掉对应索引行并修正元标签 → 生成新的 m3u8。
全程不缝合、不重编码、不动物理分片。

## 功能特性

- **三层广告识别规则**
  1. 关键词匹配：命中 `ad`、`promo`、`vip`、`advert`、`广告`、`片花` 等关键词的分片
  2. 时长校验：以 `#EXT-X-DISCONTINUITY` 为边界，识别时长异常的广告块；无断点时退化为滑动窗口扫描
  3. 断点锚定：结合 DISCONTINUITY 结构确认前两层标记
- **覆盖原文件**：可选直接覆盖原文件，或另存为 `[去广告]xxx.m3u8`
- **实时统计**：识别后显示「已发现 N 段广告」，保存完成后显示「已移除 N 段广告」

## 使用说明

以夸克浏览器下载的视频为例。

### 1. 找到 m3u8 文件

夸克下载的视频通常保存在手机内部存储的 `Download/QuarkDownloads/` 文件夹，
部分缓存视频位于 `Android/data/com.quark.browser/files/Download/Video/`。

一个 m3u8 视频通常由两部分组成，二者需放在同一目录：
- `视频名.m3u8` —— 索引文件
- `视频名/` —— 同名文件夹，存放 `.ts` 分片

> 本工具只处理 m3u8 索引文件，若夸克下载的是单个 mp4 则不适用。

### 2. 选择文件

打开 AdPrune，点击文件夹图标，进入下载目录选中 `.m3u8` 文件（支持多选）。

### 3. 选择是否覆盖原文件

- 关闭「覆盖原文件」（默认，推荐）：另存为 `[去广告]视频名.m3u8`，保留原文件。
- 开启「覆盖原文件」：不添加「去广告」前缀，直接覆盖原文件。

### 4. 开始处理并保存

1. 点击「开始处理」，等待识别完成。
2. 结果区显示「已发现 N 段广告」，并给出总分片、广告段、移除时长、剩余时长等统计。
3. 点击「保存全部」：
   - 首次保存需选择保存文件夹（建议选原视频所在目录）。
   - 之后会记住该目录，直接写入。
4. 保存完成后显示「已移除 N 段广告」。

> 若保存时提示「未获得所有文件访问权限」，点击「去系统设置开启」跳转到权限页，
> 打开「允许访问所有文件」开关后返回，重新点击「保存全部」即可。

## 环境要求

- Python 3.11+
- Flet 1.x

## 本地运行

```bash
pip install flet
flet run
```

## 打包 Android APK

```bash
# 打包前先应用跳转补丁（幂等，可重复运行）
python patch_url_launcher.py

# 模拟器（x86_64）
flet build apk --arch x86_64

# 真机（多架构）
flet build apk
```

> ⚠️ 每次重新下载依赖或更换构建环境后，需重新运行 `python patch_url_launcher.py`。
> 该补丁修复了 Android 11+ 上「去系统设置开启」按钮无法跳转到权限页面的问题。

## Android 权限说明

本应用需要「所有文件访问权限」（`MANAGE_EXTERNAL_STORAGE`）才能读取任意目录下的 m3u8 文件。
该权限属于特殊权限，系统不会自动弹窗请求，需在应用内点击按钮后手动开启。

